# FLAYZ YOU (TikTok Mod & Region Changer)

Официальный модуль **FLAYZ YOU** для смены региона в TikTok, разблокировки функций и обхода региональных ограничений.

## Особенности:
- **Название:** FLAYZ YOU
- **Telegram канал проекта:** `https://t.me/+H135_eOHfuY4OWEy`
- **Функционал:**
  - Обязательный переход в официальный канал перед сохранением конфигурации.
  - Выбор любого региона (США, Казахстан, Беларусь, Германия, Великобритания, Турция, ОАЭ).
  - Снятие ограничений на скачивание видео без водяных знаков.
  - Подмена MCC/MNC и сетевых query-параметров.

## Сборка APK:
1. Откройте проект в **Android Studio** (`C:\Users\bogda\.gemini\antigravity\scratch\TikTokRegionMod`).
2. Нажмите **Build** -> **Build APK(s)**.
3. APK файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
